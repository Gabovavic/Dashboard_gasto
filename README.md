# Ejecución del gasto del Gobierno Central presupuestario

Dashboard de la ejecución mensual del gasto del Gobierno Central presupuestario, a partir de los informes de ejecución de la Dipres.
Se actualiza cada mes con el código del Consejo Fiscal Autónomo (CFA).

Elaborado por Gabriel A. Valenzuela Vicencio con ayuda de Claude Opus 5.5.
